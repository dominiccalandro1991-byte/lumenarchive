# LumenArchive

LumenArchive is a local-first, creator-controlled storyworld platform prototype for protected canon, connected media planning, Living Story Rooms, rights provenance, continuity review, and release gating.

## Status
This build uses seeded browser-local demo data. AI, media generation, authentication, database, payments, publishing, voice, and external provider integrations are not connected. Any simulated suggestion or playback is explicitly labeled.

## Run
Use the project preview. The app is designed for iPhone Safari from 320px upward, with desktop studio navigation as an enhancement.

## Product rules
- Canon changes require versioned change requests.
- AI assistance is never authoritative.
- Rights, consent, provenance, accessibility, and approvals are release gates.
- Publication is local prototype state only.

See ARCHITECTURE.md, DATA_MODEL.md, ROUTES.md, and PROJECT_STATUS.md for implementation truth.

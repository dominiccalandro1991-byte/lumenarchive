# Decisions

- Local-first persistence is used because the specification requires a functional prototype without paid services.
- Seeded Glass Tide data is deterministic and explicitly labeled demo data.
- Protected canon is enforced through change requests instead of direct mutation.
- Release validation fails closed and exposes exact blockers.
- Simulated AI/media behavior is separated from provider interfaces and visibly disclosed.
- A single world is used in the first build to make cross-media continuity inspectable.

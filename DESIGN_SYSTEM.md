# Design System

LumenArchive uses a dark editorial archive aesthetic: ink navy background, warm ivory text, muted slate surfaces, brass gold for action, orchid for speculative media, teal for verified evidence, moss for approved state, amber for review, and crimson for blockers. These are semantic tokens, not direct utility colors.

Typography uses Geist for interface readability and a restrained serif display face for story titles. Layout is flex-first, mobile-first, with 44px touch targets, safe-area padding, bottom navigation on mobile, and a persistent studio rail on larger screens.

Motion is limited to purposeful opacity/translate reveals and respects reduced motion.
